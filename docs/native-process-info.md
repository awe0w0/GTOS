# 原生任务自查询 ABI

32 位原生 V8 初始化需要知道当前任务身份、用户栈边界及实际地址空间限制。此接口从内核当前任务返回这些信息，不接受其他任务的 ID。它是 GTOS 独立 ABI，不使用 Linux 系统调用号。

## 调用与布局

`int 0x80`：EAX=`GTOS_SYS_PROCESS_INFO`（0x4713），EBX=请求的无符号用户地址，ECX=16。成功返回 EAX=0；失败返回负错误码。其余通用寄存器、段寄存器及用户继续执行的位置保持不变。请求和结果均由 [info_abi.h](../include/process/info_abi.h) 定义，每个字段是 32 位无符号整数。

| 请求字段 | 值 |
| --- | --- |
| version | 1 |
| flags | 0 |
| result_va | 48 字节结果的可写用户地址 |
| result_bytes | 48 |

结果按顺序包含：版本、process_id、thread_id、stack_begin、stack_end、user_begin、user_end、page_bytes、maximum_pages、maximum_regions、maximum_parallel_threads、scheduler_cpu_count。

当前原生进程只有一个任务，使用独立地址空间。因此两个 ID 相同，并与内核实际接纳的任务 ID 一致；不同的活动进程及回收后重新接纳的进程具有不同 ID。ID 是无符号值，不保证能转换为有符号 int。V8/C++ 适配器必须在转换前检查范围。

栈为 [0xBFFFD000, 0xBFFFF000)，不包含保护页。用户地址范围为 [0x40000000, 0xC0000000)，页大小为 4096。现有每进程上限为 256 个用户页、32 个动态预留区域；用户页包括静态加载、用户栈和已提交的动态页，不包括页表、目录及保留的内核栈。预留区域不等于驻留页数。

BSP 调度器只提供一个逻辑调度 CPU，原生进程尚无共享地址空间线程。这些值描述现有运行时的限制，不能用来推断物理 RAM、可用内存、峰值内存或完整 V8 的资源需求。

## 检查顺序与失败行为

内核依次检查 ECX 的精确长度、复制整段请求、版本、flags/结果长度、验证整段可写输出，最后读取当前任务信息并复制结果。

- 请求长度错误、非零 flags、结果长度错误：-22。
- 任意请求字节不可读或任意输出字节不可写：-14。
- 版本不支持：-38。

失败不会修改任何输出字节。输入可以位于只读页；输出必须完全可写。未对齐地址、完整或部分输入/输出重叠均可使用，因为内核在写输出之前已经消费完整请求。跨页、溢出、内核地址、未映射页、只读输出或混合页权限均经过整段检查。

查询不分配页、区域或堆内存，不调度、不让步、不更新时钟，也不暴露 CR3 或内核指针。既有地址空间及页数限制没有因本模块而提高。

## 验证

```sh
CXX=/absolute/path/to/g++-13 \
  ./tests/native_process_info_smoke.sh /absolute/path/to/fresh-artifact-directory
```

必须使用尚不存在的产物目录及 GCC 13 或更新版本。脚本构建真实的独立 IA32 ELF 与诊断内核，在 O0/O2、32MiB/单 CPU 和 64MiB/四 CPU 下执行。每次启动有两个原生同伴、一个 ring0 同伴及保留的启动任务；调度仍限定在 BSP。

每个被验收的原生程序执行 53 次查询：14 次成功、39 次失败。50 次完整 8192 字节比对检查失败输出、页边界、未对齐地址、只读输入及请求/输出重叠。测试还独立观察当前 CR3 与接纳 ID 的对应、非结果寄存器、调度统计、时钟及空闲帧数。

正常退出、用户保护页故障和外部 RequestExit 各重复两轮。每个受测进程保留两个动态数据页及一个页表，停止后先检查内容和完整资源成本，再执行延迟 Reap；原生同伴、ring0 及启动任务必须继续进展。最后两个原生同伴关闭后，空闲帧数必须恢复到原始基线。

阶段轮询在同一个中断保护范围内读取完整记录和运行状态，避免正常退出发生在两次读取之间而被误判为过早退出。等待 PIT 中断在该保护范围之外；真正未发布完成阶段就退出的程序仍然验收失败。

初始化期限为 2000 个已交付 PIT 中断，每个客机还有 180 秒的独立宿主运行期限。完整字节比对和两个忙碌同伴在 O0 下需要调度时间；期限不替代任何功能断言。每轮记录实际编译命令、工具哈希、输入快照、ELF/ISO、栈边界证明及真实客机日志。验收解析器还必须拒绝对这些日志的缺失字段和破坏控制。

这些证据仅证明自查询 ABI 与现有运行时的集成。完整 Isolate、C++ 线程库、Chromium 网页浏览、视频和 HTML5 仍需要后续实现与真实原生运行验证。
