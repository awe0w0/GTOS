# 自审

先比较三种解释：公共头缺声明、整数宽度或 errno ABI 不匹配、GN 没有纳入
真实提供者。实际头已声明，完整46缺少四项定义，原 GN 两组 sources 也确实
未列出四文件。因此仅接入固定实现，保留原 flags、引擎配置和函数体。

分类验证 EOF、负数、256以上及所有字节。整数解析验证 long/long long 的
32/64位宽度、正负极值与溢出后的持续扫描、endptr 精确位置、ERANGE、EINVAL
及原 errno 保留。非法进制不改 endptr，依据固定 parser 和上游测试选择断言。
没有将另一 libc 的约定强加给固定 LLVM。公开函数指针防止优化成常量。

真实 Errno 赋值符号和 libc_errno 对象的 ABI 与已验收 external 模式4提供者
匹配。每个上下文使用不同 errno 标记并在 Yield 后检查；继承存储隔离测试和
共享 errno/TLS 负对照继续验证所有权。工作线程在初始化之前调用解析 helper，
父线程按阶段等待，因此不声称所有线程同时解析，也不据此宣称完整 libc 线程安全。

初次对象检查错误地要求直接导入 __llvm_libc_errno，而真实模式3通过类方法
间接调用；修正的是私有断言。初次小调用者链接缺 GetCurrentThreadId 包装，
后续链接采用完整目标中已存在的真实 platform.o。一次输入 SHA 录入错字在
链接前被拒绝。三次失败均保留，未计为通过；未修改运行库来迎合错误断言。

76上下文、145358检查和48次 Join 通过；取消、OOM及页故障的诊断是预期负例，
退出码、模式、任务/FP/页帧和回收数必须同时匹配。共享错误存储必须失败。
默认配置仍只允许一个上下文；多线程配置最多四上下文，调度仍在 BSP。

完整47绑定全部实际链接文件、准确 GN/引擎配置及新对象完整依赖，复用原平台
归档，不把旧对象来源证明称为重新编译。旧缓存字节和元数据未变。四符号已
消除，但 SetDataReadOnly 等真实缺口仍在；不能用返回成功的空实现掩盖页权限。
完整 ELF、Isolate、浏览器、视频、HTML5 和整个调用链栈界均未验收。

构建入口为静态审阅和哈希锁定文件，参数数组 shell=False、最小环境、无网络
命名空间、no_new_privs、Landlock 精确工具执行权及新输出目录写权限持续生效。
