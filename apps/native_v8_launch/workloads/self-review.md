# 自审

修改前对照实际执行与“仅调用 API”两种解释：GC 必须有真实回调，microtask 必须改变
同一 Context 中的 JS 状态，异常必须在捕获后继续运行脚本。掩码不在进入用例时置位，
只在结果正确后置位；外部观察器同时要求最终退出阶段、返回值和精确回收通过。

GC 回调只递增整数，不分配、不运行 JS。跨 GC 只保留 V8 Local/Context 和由 JS 全局
对象持有的 buffer，不保存移动堆裸指针。临时 Utf8Value 在句柄作用域内使用和销毁。
TryCatch 在预期异常作用域结束后销毁，后续脚本使用新的捕获作用域。进入 Isolate 后
显式选择 microtask 策略，不依赖隐式 API 退出时的 checkpoint。

原 V8 参数、内核预算、原生堆和文件/线程等实现未变。完整链接仅替换一个 main 对象，
必须保持另外 1109 个输入的字节、顺序和缓存元数据；客机内核只替换观察器，复用
已验收的 25 个核心对象并重新执行内核指令审计。新增入口不扩大任何用户权限。

宿主不执行 GTOS ELF。构建与客机验证在无网络命名空间中完成；精确工具白名单、
最小环境、Python -I -B -S 和新目录写入限制维持。新增头文件先核对固定版本原始
Git blob，平台覆盖头与既有 payload 锁核对。输入不完整时失败关闭，未放宽检查。

本补验不覆盖 TypedArray 全部越界行为、GC 压力/并发、复杂 Promise 排序或全部异常
类型。前序堆/启动/默认进程回归仍是对应源码的已有资格；本轮不将它们记作重新运行。
Browser/HTML5 和完整冷构建状态继续为 false。
