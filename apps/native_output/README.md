# 原生格式化FILE输出

完整V8目标缺少OS::PrintError触发本模块。六项OS输出包装复用固定LLVM
generic printf/fprintf/vprintf/vfprintf与既有FILE；PrintError最后fflush(stderr)。
同时补齐FILE到原生SYNC的接线，以及w/w+截断打开的提交和读者缓存语义。

## 实际验收

- 32M/1CPU与64M/4CPU：12个CPL3任务、12次精确回收、161842项检查和428个
  篡改日志反例；六种正常/故障/取消/回收Flush失败及锁误用模式。
- 控制台与文件重定向、浮点、3000字节未截断输出、errno/ferror、OOM与恢复；
  保留每任务46项标准流检查及原常规FILE/PNG检查。
- 旧读者缓存和游标、新读者空文件可见性、真实截断Open Flush失败及句柄清理。
- 未修改的stock LittleFS以rb冷挂载两盘，核对常规文件、格式化前缀/长文本、
  恢复/OOM后缀及1108字节PNG；读回前后磁盘哈希不变。
- 完整目标保留5160条对象命令和引擎参数，只替换两项FILE提供者实际重放。
  已越过OS::PrintError，首个剩余未定义符号ceilf；默认20项诊断限制未改，
  错误列表不视为穷尽。

probe/冻结实际消费者、客体内核、观察器与独立读者源码。构建使用源码锁内的
固定工具和既有原生ABI/启动/VM/FILE提供者；精确命令、完整依赖、输入哈希和
原日志见acceptance.json引用的工作区产物。旧失败、缓存与原文件备份保留。
公有源码及1287项载荷文件已核对字节，未重跑公有GN或客体，也未运行新的远程CI。

资格限定私有IA32单用户任务配置；全调用链栈界限与并行线程未证明，I/O失败
不承诺原子回滚。完整原生V8 ELF、Isolate/JS、浏览器、视频/HTML5尚未验收。
生产镜像和可见虚拟机磁盘本轮未更新。
