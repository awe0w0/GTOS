# 原生虚函数 ABI 终止

完整42的真实首错是V8 AssemblerBase和MacroAssemblerBase虚表引用的
`__cxa_pure_virtual`。本模块把固定libc++abi `cxa_virtual.cpp`加入既有ABI库，
原源逐字节保持。两个真实C符号pure/deleted均调用现有诊断和`abort()`，
不返回。5174条旧对象命令、引擎参数和最终次序保持，只加一个对象。

消费者用volatile函数指针导入两个真实ABI符号，禁用builtin。缺提供者的
链接必须同时失败在两个符号；加入提供者后无未定义符号。实际原生入口
保持，主函数返回后的失败标记不得出现；真实终止码是`0x48000021`。

32M/smp1和64M/smp4各运行八个任务，涵盖pure/deleted正常诊断，以及真实
诊断写完成后注入的EIO、零和超长返回。格式器必须记录固定非Linux映射
的EDOM33，不重试已经写出的诊断，然后真实panic写和abort继续发生。
这是明确的返回值故障注入，不是实际磁盘故障。早期错误预期EIO5的失败
完整保留，只按固定来源校准验证预期，不改库或削弱断言。

每个任务保留实际malloc堆和两个哨兵，内核核对实际CPL3、私有CR3、诊断
字节、寄存器和系统调用计数、原生入口状态及停止成本，再精确回收。
两配置16个任务/16次回收，12次返回故障控制、64项消费者检查；464项日志
反例全部拒绝。同伴、帧、堆及FP所有者恢复。42个ELF加载页，消费者最大
单函数44字节，提供者0字节，trap入口观测376字节；不证明完整调用链栈界
或并行用户线程。完整目标重放与公开字节对应另列验收状态。

消费者/提供者编译锁定实际完整pre-M/post-MD闭包、工具和GN配置；小对象
阶段不宣称重哈希所有无关GN源，正式GN和完整目标另行核验完整输入。
完整V8 ELF、Isolate/JS、网页、视频和HTML5尚待验收，生产镜像未改。
