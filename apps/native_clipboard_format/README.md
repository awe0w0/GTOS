# 原生剪贴板格式类型

本模块为 GTOS 的 `ClipboardFormatType` 接通现有 MIME 字符串实现。完整原始
`clipboard_format_type_aura.cc` 保持原样，只在头文件的平台条件中接入 GTOS，
并让实际 GN 目标选择该实现。未启用 Aura，也未添加系统剪贴板传输服务。

`patches/` 保存完整实现、声明和 GN 文件；`probe/` 保存独立诊断目标、标量 C ABI、
对齐启动代码、链接脚本和内核观察代码。回归覆盖标准 MIME 与 PNG/Bitmap 别名、
序列化的 NUL/非 ASCII 原始字节、比较、复制与字符串所有权、生命周期、自定义格式名
及索引边界。非 ASCII 自定义格式负例保留真实 CHECK、abort 和堆 panic 路径。

## 实际原生回归

- 32MiB/smp1 与 64MiB/smp4 各两轮正例，共四个 CPL3 上下文。每轮 289 项断言、
  67 次系统调用、两个真实构造函数，正常 exit0，阶段与结果标记完整，没有用户故障。
- 每轮覆盖 12 项标准 MIME/别名、14 项序列化、100 对比较、32 轮字符串所有权与生命周期、
  四项 ASCII 自定义名及四项 Web 自定义索引。Deserialize 保留 NUL 和非 ASCII 原始字节；
  长度抽查 0、1、7、15、22、23、24、31、255、4096。来源销毁后的两份拷贝累计核对
  66272 字节，返回的序列化副本可独立修改。
- 非 ASCII CustomPlatformType 由未修改的真实 CHECK 拒绝，两次均保持 stage10，调用
  abort/heap panic，以 SYS_EXIT `0x48000021` 终止。每次 51 次系统调用，常规 exit 标记
  保持未完成，没有 fault。任意非零退出、故障或 CHECK 返回均不能通过。
- 两种模式停止时均为 16 个动态页，跨两轮没有增长。Reap 每次先返回 1、再次返回 0；
  正例分别恢复 4729/12913 空闲物理帧，负例恢复 4730，任务数回到一个独立 peer。
  FP 初始化/失效计数为 1/1、2/2，无不变量失败，peer 和 PIT 继续运行。

FP 的本轮结论是上下文生命周期和释放，没有新增寄存器逐位恢复实验。smp4 配置仍使用
既有 BSP 调度范围。每个 ELF 为 2249 个映像页，沿用 128 栈页、1024 动态页上限，
总容量 3401；没有扩大原有可信启动配额。

## 正式图与来源

实际完整 GN 图包含 21501 个目标、2518 个文件，保留旧 owner、工具链规则和 Content
依赖。三个 C++ 单元完成完整 M/MD，依赖数为 450、45、45；原格式完整对象及其 933 项
闭包复用。独立小写 `.s` 实际不生成 depfile，证据只采用唯一已锁源码、正式规则、真实
汇编结果及精确诊断，不补造 MD。五个用户对象的全部 12660 字节可执行代码逐节审查。

两个新 ELF 均由真实 LLD 链接，使用 1253 个既有提供者及四个本轮选定对象；保留 21 个
实际消费的格式 ABI、两个构造函数，零强未定义符号。每个观察内核的 35 个显式对象
均完成完整指令审查，包含 14 个原始整数归档成员。

heap 和 exit 额外各执行一次独立完整 M，两个原对象不重编。exit 使用原 CXX 所用的
实体源码副本及固定 Clang 资源头，核对文件和全部祖先、双旧内容哈希；113 个原始
依赖条目、111 个唯一来源及两组路径别名分别完整比较。旧深层源链接不纳入本轮来源。
旧失败、修正理由及 CHECK 提供者的历史来源范围见[资格复审](provenance/qualification-review.md)。

`receipts/`、`logs/` 和 `provenance/` 保存来源及验收证据；`source-lock.json`
另行绑定八项既有内核接口文件。`replay/` 是本工作区固定入口的副本，依赖锁定的工具、
源视图和缓存，不宣称空白主机冷构建通过。仅复制源码、文本日志、锁和回执，不发布二进制。

`provenance/blink-enums/` 单独保存 Origin Trials 与 Runtime Feature 两个原始生成器
的完整成功证据、schema 和源码锁，分别生成 99 和 8 个枚举成员；这些结果不代表
Mojo C++ 或 Blink 已运行。

执行遵循[本地命令栅栏](../../docs/native-command-execution.md)：固定工具与哈希、
Python `-I -B -S`、最小环境、无网络命名空间、Landlock 精确执行叶与新输出目录。
本模块范围不包含桌面剪贴板数据服务、Content、网页、视频或 HTML5 运行，也未更新生产镜像。
后续继续实际 Content 入口及浏览器主线。
