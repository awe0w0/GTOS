# 原生进程退出与析构登记

完整38的__cxa_atexit缺口驱动本模块。退出目标局部复用固定LLVM登记算法，
加入dso选择、逆序/重复终结及回调重入，保留合法空首块与真实owner锁。
正常main返回和C exit统一处理TLS、静态/C回调、逆序fini、新登记及C流关闭；
故障、取消和abort由内核回收。现有TLS/DSO定义及FILE布局保持。

32M/1CPU与64M/4CPU共14个CPL3任务、14次精确回收通过，每任务529项登记
检查，全套7660项检查；536个日志反例被拒绝。覆盖32项无堆登记、跨块DSO
选择、OOM恢复、嵌套终结、真实编译器全局构造/析构、main返回、C exit、
回调故障/取消、活跃登记取消、abort和真实关闭Flush错误。

成功关闭实际读回MTCGbaN与S，证明TLS/C/全局/fini/新回调/FILE顺序。
两次关闭Flush错误仍释放句柄并保留退出码31，实际读回0和1字节，不承诺
新数据提交或I/O失败的原子回滚。堆、页帧、FP所有者和ring0继续运行通过。

probe/保存实际消费者、内核和观察器源码。entry-symbols.h由验收中的实际
ELF两个RW状态符号生成：地址严格限制在0x40040000–0x40041000，不能使用
其他ELF地址替代。精确工具、命令、完整依赖、源哈希及日志见acceptance.json。
公开源码逐字节对应检查不等于重跑公开GN/客体或新远程CI。

资格限于私有IA32单用户任务配置；不证明DSO装载/卸载、共享线程、全调用链
栈界限或完整POSIX。完整V8 ELF、Isolate/JS、浏览器、视频和HTML5仍待验收。
生产镜像与旧盘未改。本批未另做stock冷挂载，现有FILE/数学资格按哈希复用。

完整39已实际链接，12617项输入及旧缓存终验通过；当前首阻塞为libc++
__next_prime(unsigned int)，消费者包括V8的__hash_table。默认20项诊断
不代表全部缺口，退出四符号未再出现在本次诊断中。
