# 模块自审

复核了两种竞争解释：仅补V8构造可继续链接，但Start/Join/Semaphore仍缺，
且调用者Run无法满足真实线程约定；根因是内核无共享地址空间生命周期。
本次实现有界真实上下文，保留现有容量和默认诊断配置，不补假成功符号。

- 所有新系统调用先确认opt-in；请求全量快照，错误输出保持原值。
- 入口来自可信装载计划的可执行段；非PAE没有NX，不宣称运行时硬件禁执行。
- reservation首尾按完整页验证，中间整段RW；用户不能以堆或主栈替代。
- 创建前检查容量/栈占用。调度和所有权发布在IF=0，copy失败移除任务、
  恢复原栈字节并退休FP。ID单调，join不重复消费；当前栈不作回收。
- 两进程共享虚拟栈地址也不共享物理所有者，真实跨owner join负例通过。
- worker的文件访问使用root owner和root空间；worker退出不调用ReclaimOwner。
- root StopGroup只终止同组，Reap先移除全部Task引用再Destroy，FP仅退休一次。
- 4个总上下文复用原4个已注册FP记录，不扩大硬件记录白名单或调度CPU数。
- 默认false路径另跑真实FOpen消费客体；8任务正常/取消/故障回收通过。
