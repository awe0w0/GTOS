# 原生 V8 平台辅助接口

本模块补齐共享库枚举、外部代码移动标记、路径分隔符、IA32 调用栈对齐查询、UTC 毫秒时间和有界 `StrNCpy`。完整 V8、Isolate、网页浏览、视频及 HTML5 仍以完整目标运行证据为准，不能用本模块消费者代替。

固定 V8 契约允许共享库枚举和外部 GC 性能标记不执行操作。GTOS 加载器只接受静态 ET_EXEC，并拒绝动态段、解释器和动态符号表，因此共享库列表为空；当前内核没有 Linux ll_prof.py 使用的可执行映射事件流，GC 通知保留为空操作。V8 自身的代码移动日志保持原有行为。

目录分隔符为 `/`，对所有 256 个字节验证分类。IA32/SSE2 对齐约束为 16 字节，由根线程和 worker 实际调用的汇编入口独立检查。`TimeCurrentMillis` 与固定上游一致调用 `Time::Now().ToJsTime()`，使用已有 CMOS/PIT UTC 服务。私有客机固定虚拟 RTC 为 2026-10-15 04:05:59 UTC，通过真实 UTC 系统调用前后夹取结果，验证毫秒单位、日期范围及每线程 errno 保持；不修改宿主时钟。

`StrNCpy` 保留 `strncpy` 的 n 字节复制与零填充语义，截断时不额外写 NUL，n=0 不访问源和目标。复制前检查长度非负、n 不大于目标长度，以及非零复制的非空指针。无效调用走既有 UD2 诊断路径，不返回虚假的成功状态。该检查不替代 C 指针对其实际对象范围的责任，也不支持重叠复制。

默认及 BSP 四上下文两组、32M/smp1 与 64M/smp4 控制共 44 个实际 CPL3 程序、68 个上下文、24 次 Join 和 44 次进程 Reap。覆盖零填充、满宽截断、全部非零字节、保护页边缘、五类非法参数，以及上一模块的文件、标准流、同步和故障/取消回收。20 个非法复制程序在 vector 6 停止，内核独立确认目标缓冲未变，文件、物理页和 FP owner 精确回收。

实现只替换现有平台对象，GN 图与输入顺序保持。完整链接重建真实 38 成员归档，只替换平台成员，其余 37 成员逐字节保留。详细结果见 [acceptance.json](acceptance.json) 和 [self-review.md](self-review.md)。生产镜像未改，私有客机控制不表示生产虚拟机已更新，也不声明用户态 SMP。
