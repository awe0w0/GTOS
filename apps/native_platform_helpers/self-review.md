# 自审记录

## 契约和实现

- 固定 `platform.h` 明确允许两项外部性能分析接口无操作；加载器源码拒绝 ET_DYN、PT_DYNAMIC、PT_INTERP、DYNAMIC 和 DYNSYM。空列表依赖当前真实静态加载模型，不构造假的库地址，也不影响 V8 内部代码移动事件。
- IA32/SSE2 调用约束取固定上游的16字节。测试汇编直接计算函数入口的 `(ESP+4)&15`，根线程及三个 worker 各自调用，不用查询常量自身证明栈布局。
- UTC 时间保持真实 `Time::Now().ToJsTime()`，链接和符号检查要求实际 `Time::Now` 导入。客机另外发起原生 UTC 请求夹取读数，防止把开机微秒误用为 epoch 毫秒。既有时间桥接与内核 RTC 实现未改。
- 字符复制先拒绝负长度、超出目标长度及非零复制的空指针。短源遇到首个 NUL 后只写零，不再读取后面的源；截断最多读写 n 字节，不在 n 之外补终止符。n=0 的空指针不被解引用；SIZE_MAX 比较在 size_t 域完成。
- 五类非法调用分别为目标长度不足、负长度、空目标、空源和 SIZE_MAX。不能以任意异常当作通过：要求 UD2/vector6、指定退出码、无用户断言错误，并从保留地址空间读回32字节目标哨兵。错误返回、页故障或先写后终止都会被拒绝。

## 验证范围

测试使用真实 LLVM libc/标准流入口和原有有界四上下文服务。保护页由已验收的原生 VM ABI 创建，不公开或绕过 V8 私有内存接口。前一页按需提交读写，后一页保留不可访问；短源零填充和满宽目标分别放在页边缘。每线程重复执行接口，保留独立 errno，结束后核对资源与 FP owner。

既有文件控制仍覆盖真实临时文件、碰撞、ENOMEM/EMFILE、EROFS、I/O 错误、标准流析构、同步，以及故障和外部取消。四上下文仍是 BSP 调度，smp4 仅为启动配置控制。

提供者采用既有实际 GN 参数，完整 M/MD 前后集合相同；新函数未改变公共头或 ABI。完整目标重放保留实际 GN 顺序和已锁定对象，只在真实38成员归档中替换平台成员。旧规范文件通过已保存的哈希映射读取，旧缓存和失败不覆盖。

驱动初次漏查已按固定哈希绑定的候选源码；随后消费者输入清单漏列直接引用的当前 UTC/file ABI，均在编译前停止并保留。它们已按先前客机及当前提供者的精确字节补齐。夹具曾调用 V8 私有内存接口，被编译器拒绝；修正为原生 VM 保护页，运行实现未因这些驱动/夹具问题改动。

当前只声明本模块范围。完整 V8 ELF、Isolate、浏览器、视频、HTML5、生产镜像与远程 CI 的结果分别记录，不从独立消费者推断整体完成。
