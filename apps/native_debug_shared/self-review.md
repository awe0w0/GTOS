# 自审与验收记录

范围由 full57 的七项真实未定义符号限定，没有提前扩充内核容量或引入新的共享 ABI。

## 已检查的竞争解释与边界

1. 完整目标缺少栈迹符号，不代表应加入 POSIX 后端：GTOS 没有该信号/展开服务。
   common 构造和析构已存在，故只实现系统相关的四类操作，避免重复符号。
2. 固定空 PC 可以让链接通过，却不能记录当前位置。当前 noinline 构造使用 level0
   返回地址；测试用两个不同调用点及其代码地址范围排除固定 PC。无可信展开信息时
   不追踪帧链。复制/超限数组构造继续使用锁定 V8 的既有实现。
3. Print 委托给 OS::PrintError 并非自动安全。真实 platform_file.cpp 的关闭操作
   清空 stderr，而 vfprintf_internal 直接锁定该指针。修订版先检查 null 并设 EBADF。
   客机 mode2 关闭真实 stdout/stderr 后检查结果，随后走原始退出及回收路径。
4. 共享分配不能用私有分配替代，否则句柄/偏移、别名和所有权全部失真。
   当前 ABI 没有相应服务，所以显式返回失败；共享释放不能误删私有保留区。
   mode10 的内核在 Reap 前读取被误交页，检查仍映射且32字节标记保留，随后精确回收。
5. 区域命名失败不应阻止原有子空间继续使用。用真实 VirtualAddressSpace 接口验证
   命名失败、共享分配失败及后续私有页释放；没有修改头文件可见性绕过私有接口。
6. 新格式输出用 ostream::write，避免改变调用者格式状态；Print 使用真实 FILE。
   没有分配假 FILE、伪造输出字符串或把目标代码拿到宿主执行。

## 限制

这是一帧原始地址报告及不支持能力的明确失败语义。它没有提供多帧展开、符号化、
信号处理安装、共享内存或区域命名。各行打印分别使用 FILE 锁，不承诺整段多行
报告跨线程不可交错，也不支持与关闭同一 FILE 并发使用。浏览器、视频及 HTML5
继续保持未运行状态。生产镜像未变，现有 VM 镜像无需因此重启。
