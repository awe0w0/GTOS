# 自审记录

审查范围为 20 个覆盖文件、866 个复用 SDK 基础文件、17 成员真实归档和新增消费者。
编译/链接/来宾证据来自实际执行，未把生成 GN 图或叶子对象等同于浏览器运行。

- 平台判断：`IS_GTOS` 默认为 0，只有独立 GTOS 目标启用。混合 OS 身份直接报错；
  其他平台判断和 PA 生成标志保留。GN 只对 GTOS IA32 加入两个原生身份提供者。
- 线程/errno：32 位正 ID 来自直接自查询，避免分配器锁中初始化 TLS 或分配内存。
  Sleep 负/零时长不会调用服务；正时长拆成秒和纳秒，失败不伪装成功。errno 使用
  既有真实原生线程状态，嵌套作用域和诊断后的保留均由消费者核对。
- 写入边界：每次请求至多 256 字节，只对 1..本次请求字节数推进指针；负错误在
  无符号返回类型中也大于请求，因而停止。strlen 仍要求有效 NUL 结尾字符串，
  未新增任意坏指针可恢复承诺。空值、抑制、完整块及跨块输出已实测。
- 格式化：保持上游整数和浮点代码，仅为 GTOS 选用已有标量类型声明。截断与最小
  有符号整数已实测；没有删除浮点消费者来隐藏未完成的数学/时钟/随机提供者。
- ABI：V8 main 保持原有 GN 配置，PA 消费者保持实际 PA GN 配置；接口只传递 C int。
  SDK 使用 ABI1 和真实外部线程声明，C 专用无线程配置头未进入当前源视图。
- FATAL：处理器为空，实际析构函数输出后触发上游 int3/ud2。根据原有 DPL0 门与
  Intel 权限规则，在执行前将观察器精确预期订为 #GP13/error0x1A。没有修改门权限、
  换成手写 abort 或接受任意故障。128 KiB 未释放映射、端点字节、未返回标志、
  活跃内核任务及完整帧回收在两种配置均成立。
- 输入完整性：归档构建前后检查 3214 个输入和 1656 个别名；新增正常/异常消费者
  分别检查 474/473 个实际 MD 依赖。完整链接重哈希所有实际对象、归档、脚本与
  工具，保留其顺序和旧缓存元数据。历史源码资格通过固定证明复用，未重编整个 V8。
- 执行边界：固定 Python/Clang/LLD/Ar/NM/BFD/objdump/QEMU 文件；只允许各阶段所需
  精确执行文件，没有目录执行权。输出只写新的指定目录；所有隔离失败均停止。
  未扫描其他进程、读取凭据、改 hooks/安全设置、清理缓存、删除输出或强制推送。

残余边界与 README 一致：未验收全部归档外部服务、完整 PA/Dawn/Content 或冷构建；
未将短写/错误返回注入实测。没有生产内核、运行库或 ISO 变更。四份来宾日志和
机器记录可以分别核对普通 V8 完成与故障终止，二者不互相替代。
