# 自审记录

启动状态的 release/acquire 发布覆盖内核写入的线程 ID。worker 首次调度
可能晚于 Join，因此入口允许 started 或 joining；必须真实 TRY_JOIN 完成
后释放工作栈。创建失败释放未固定的栈，并清理固定头文件 StartSynchronously
失败返回路径的信号量。已启动但未 Join 的对象不允许析构。

信号量每次 CAS 只消费一个许可，零/负期限不等待，正期限使用真实单调时间
差避免截止时间相加溢出。负计数及有符号计数溢出被拒绝。

TLS key 登记独立加锁，值按线程和代际区分；key -> TLS storage -> heap ->
context 的锁序与已验收清理路径一致，析构回调在这些锁之外执行。公开源码
与私有验收字节须由发布步骤逐文件核对，不能用初步编译冒充新 GN 验证。

原生客机验证覆盖正常退出、取消、OOM、真实页故障、默认单线程失败、
默认栈大小、存活线程 key 删除复用、资源回收及错误共享存储负对照。
FOpen ELF 字节相同，沿用此前运行证据并明确记录未重复运行。

完整目标重放必须按真实 GN 顺序重建 libv8_libbase.a，仅替换 platform-gtos
成员，不能额外塞入散对象冒充原图。失败记录、旧源视图、缓存和原归档保留。
隔离为固定工具哈希、最小环境、无网络命名空间、no_new_privs 与 Landlock
仅新输出可写；没有凭据读取、全局设置修改、hooks 绕过或强推。

限制保留：最多四上下文、仅 BSP、仅默认优先级、无全调用链栈界证明。
共享同步、guard 等其他未验收调用仍可能拒绝多线程；完整 Isolate、浏览器、
