# 自审

先比较数值算法错误、调用 ABI 提前 quiet NaN、errno 存储错误、模拟器未报异常
四种解释。原始位输入桥、显式 volatile SSE 溢出对照及跨 yield 状态检查把问题
定位到上游 exp 的定向饱和早退；输入 0x40862e42fefa39f0、向下舍入返回正确
最大有限值，但未报告 FE_OVERFLOW。原始失败日志保留。

修订的整数位范围与原实现正有限溢出分支一致；排除正无穷、NaN 和负数。
先执行原算法，再补异常，不重新计算结果或改变 errno。准确回退、SSE2、
x87 控制和全部错误断言保留。原版 log、round 未改。

GN target 仅在 GTOS/x86 使用；base 依赖只在 is_gtos 分支添加。自审将首版
继承的 errno 模式 3 改为既有外部模式 4；没有定义新的存储。完整 M/MD、
头文件来源、缓存输入、别名和后置哈希均为资格条件；不是看到 CXX 返回 0
就计为通过。三个 ELF32 对象无硬件 TLS 或 init_array，按节索引覆盖全部
28881 个执行字节，人工审查指令在 IA32/SSE2/x87 范围。保留有意 UD1 陷阱。

参考向量未调用目标函数或宿主 libm。两种高精度计算一致，并单独检查有理数
到 binary64 的四模式编码、半偶舍入、符号零与次正规边界。此集合不构成
所有 IEEE 输入的形式化证明。按 SDK math_errhandling 检查域、极点及所有
模式的溢出；下溢报告允许实现定义，数值位及 errno/FP 状态保留仍严格检查。
标准依据为 WG14 N3220 §7.12.1：https://www.open-std.org/jtc1/sc22/wg14/www/docs/n3220.pdf 。

旧记录页位于增长后的代码内，链接断言拒绝后移至下一页 0x4005b000；原镜像
配额 256 页不变，实际各 ELF 为 92 页。四份历史 ABI 头只匹配旧回归内核，
没有回退公开装载器或真实扩展根。consumer-01、consumer-02 失败全部保留。

修正后的 guest-02 在宿主 300 秒超时前完成两项默认客体和 32MiB 正常八轮。
guest-03 必须重新核对这些阶段全部输入/别名/日志并重编字节相同完整内核，
才复用已通过阶段。32MiB 余下用例单独启动，64MiB 仍执行完整组；每条 QEMU
的宿主上限增为 600 秒，内核 20000 tick 等待及回收断言不变。旧失败聚合
绝不接受，跨启动的阶段证据单独列出。最终 guest-03 返回 0，76 个 CPL3
上下文、48 次正常 Join、153584 次数学调用及两个错误存储对照全部通过；
所有绑定输入与别名终验一致。完整根输入及旧缓存也通过终验。

公开模块只包含本次数学改动及实际探针，没有未验收的 base 其他后端。旧 V8
冻结覆盖层保留。真实扩展根实际 LLD 返回 1、未定义 17→14，无新增符号，
不将诊断驱动完成或小型数学客体冒充完整 V8/Content、网页或视频验收。
未证明全调用链栈界、物理硬件或用户 SMP；配置四 CPU 仍仅在 BSP 调度用户线程。
