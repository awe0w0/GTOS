# 自审

先推演普通互斥锁替代读写锁、写者饥饿、票号回绕、once 提前发布、TLS 退出
登记失败和析构重入，再逐项检查实际实现及故障路径。没有关闭线程、禁用
汇编、提供空 pthread、伪造 MD5 或改变其他平台实现。

- 锁内普通字段均受32位原子 gate 保护；等待前释放 gate，再真实 Yield。
  新读者不越过写队列，同线程已有读记录可重入。四个原生上下文最多四个
  未完成写请求，无符号差与票号回绕一致。第一版只覆盖三个排队写者，
  复审新增一个实际持锁写者和三个排队写者，用户及内核分别检查峰值为4。
- once 使用 acquire/release 发布完整初始化结果。pending 包含真实 tid，
  同线程递归明确失败；初始化期间不持全局锁。故障沿已有整组终止语义。
- TLS 首次登记时不持表锁分配；失败回滚后在锁外析构。成功前不发布值。
  清理先快照、释放本线程记录，回调不再接触旧记录；真实退出队列先弹出
  并释放节点，再调用析构，可以处理回调新增节点。五槽析构函数保持上游
  同索引同函数契约。没有把软件 TLS 改成宿主线程变量或自定义退出队列。
- 适配器以实际 C++23 BoringSSL 配置拥有锁类型；旧 C++20 测试仅传 C 数据
  与回调。完整 M/MD 检查包含系统头，源码来自固定提交或已验收 SDK，编译
  与执行结束均重新核对输入及路径别名。ISA 按整节原始字节检查；单函数
  SU 和目标 flags 没有被描述为完整调用链或整个消费者的反汇编证明。
- MD5 原始实现和汇编字节未改。独立宿主预期先校验七个固定 RFC 向量，再
  生成边界数据；实际目标在 CPL3 逐一检查摘要、对齐、哨兵与保留寄存器。
  三种非法访问独立触发精确页故障，不让故障掩盖正常输入测试。
- 小型客体使用与旧回归内核匹配的历史 ABI；没有回退当前公开装载器。
  默认单上下文与 BSP 四上下文均测试，故障/取消/OOM按整组语义验收。
  不宣称用户 SMP、单 worker 强杀、完整 BoringSSL/HTTPS 或浏览器通过。
- 最小补丁在新副本应用。第一次检查因本机 Git 自动转 CRLF 导致摘要不符，
  未计入通过；新检查仅对该命令固定 LF，三个结果逐字节匹配已验收候选。
  原失败、副本、冻结对象、缓存及镜像均保留，未改变全局配置和安全设置。

公开内容包含已验收新增实现、最小补丁、测试源码、原始客体日志和摘要；没有
凭据、机器标识、QQ 通信记录或宿主环境转储。公开文件以 LF 固定摘要，源
复制逐字节核对。当前根链接仍缺13个 PMA 符号，真实入口 AtExit/TLS、完整
Content/网页/视频/HTML5仍是后续工作。生产镜像未改动。
