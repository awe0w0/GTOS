## 实现与竞争解释

本模块验证实际类调用，不能只根据独立函数或链接成功认定完整类可用。FilePath 使用
完整实现与原始 UTF 提供者；LocalPMA 保留原始分配、类型与迭代逻辑，匿名区转入
GTOS VM。SysInfo 的页粒度来自真实 ABI。独立入口执行真实 bootstrap、构造与 exit，
其历史命名的数据符号不代表运行 V8 main。

匿名映射的零尺寸、32 位加法上溢及页对齐先拒绝；提交按每次最多 256 页分批。
任一次提交或前缀保护失败均释放预留句柄。释放校验前缀尺寸、句柄、范围及 VM 查询。
前缀可读且不可写，数据区可写；这不是不受信任进程内部的内存安全边界，也不构成
通用 mmap 或文件后端。实际运行确认 1MiB 数据区、257 页与析构后的旧句柄失效。

保护页 max0 情况应不读取指针；无 NUL 且限长止于边界不应跨页。14 项实际情况覆盖
这些区别。错误长度控制保留真正 libc 和类对象，只替换诊断入口，因此其精确失败
能发现检查路径未运行或返回值被忽略。两轮控制均在完整宏结束行 57 失败并真实退出。

FilePath 词法语义保留重复分隔符、父组件及无效 UTF 的替换行为；32 轮长字符串生命
周期会经过实际堆。LocalPMA 检查类型不匹配不清零、成功转换全载荷清零、迭代登记
去重及耗尽。正例每轮 121 条断言，不把单一 mask 或退出码当成唯一证据。

## 正式构建与运行证据

testonly 诊断目标。原有成员、顺序、字段及七种原生工具规则保持一致。原先遗漏
testonly 的草稿被 GN 拒绝；修正新增目标属性，没有改变 Content 约束。

五个正式 C++ 对象按实际所属目标的字段编译，完整 M/MD、符号和依赖终验通过。
消费者没有 base 的私有实现宏；实际产物仍逐字节等于已验收对象。小写 `.s` 没有
外部 include/incbin，编译器只发出未使用预处理/MD 参数警告并成功生成对象。
第一次驱动错误要求不存在的 depfile，因此整体记录失败。新终验入口绑定该失败
原因、原命令、固定单输入及实际汇编对象，不改源、不造 MD、不重跑编译。

最终六个正式对象均与原生及指令验收对象字节相同；输入、别名和产物后置检查通过。
四个成功原生上下文与两个错误长度控制的日志、映像及来源已重新绑定。正例分别
恢复 4724/12908 帧，负例恢复 4725 帧；任务/FP 精确回收。4vCPU 配置仍为 BSP 范围。
没有因正式图整理而重复不变的运行，也没有修改容量或放宽指令审查。

## 执行边界和剩余工作

静态入口和工具固定摘要；Python -I -B -S、最小环境、无网络命名空间、no_new_privs
及 Landlock 限制写入新目录，并逐个允许必要执行文件。没有内联 Python、日志命令
重放、下载执行、凭据读取、其他进程扫描或安全设置修改。Git 推送独立处理。

公开副本包括许可证、原始回执和固定入口快照。快照引用已有工作区，不声明冷构建。
历史失败仍保留，完整终验另有回执。此次没有改生产镜像，也没有触发虚拟机重启。
