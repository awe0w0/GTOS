# 自审

实现范围为三个源文件：现有 GN 目标接入九项真实提供者、新增 FILE-backed
模块化 printf 入口，以及 ldexp 入口的范围错误报告。LLVM 许可证保留；pow
准确路径、浮点格式化器和原分配器均未替换为占位实现。

ldexp 只在有限非零输入上计算缩放指数；先转换成 long long 再相加。
首位指数大于1023可确定溢出，小于-1074可确定非精确极小结果。其余精确与
舍入细节仍交给原 helper。测试包含可用 +/-2097 指数精确缩放的反例，防止
按指数参数大小误报；正负极值与普通1024/-1075边界均已在客体覆盖。

本地策略统一错误状态，不宣称解决所有 C 标准实现差异。lrint 的非法整数结果
按固定 LLVM 分支核对；公开异常码与物理状态位不同，夹具明确转换并保留原始观测。

新 printf 沿用真实 FILE 的格式化锁，关闭 stdout 的检查先于指针使用。超过
1024字节的二进制输出和浮点格式在实际文件中读回；线程记录区分原 C++ 与新增
printf 调用。长记录只验证单上下文，未宣称完成长记录并发压力测试。

原夹具的64句柄假设保留：printf 文件重定向放在该边界检查之后。观测区因真实
数学代码超过512KiB迁至1MiB，链接不重叠和数据两页上限断言保留，内核地址同步。

八个未消费 ldexp 入口头的对象逐字节复用并重验 M/MD 闭包，只重编受影响对象。
GN 原5187项命令及旧最终输入顺序逐项比较；完整链接单独重放，不以小程序
链接代替完整目标。输入终验、别名、内核 ISA 和真实回收都通过才计入资格。

所有失败与中间版本保留：依赖清单缺口、GN CPU 查询拒绝、配置清单缺项、
C++ 重载指针推导、测试区重叠、异常码判读及句柄边界污染均有原始产物。
无网络命名空间、最小环境、Python -I -B -S、精确工具执行名单、no_new_privs
及只写新目录的 Landlock 均保持。没有改动凭据、hooks、安全配置或生产镜像。

完整 V8/Isolate、浏览器、视频和 HTML5 尚未运行。用户线程仍限 BSP；不声明
通用 POSIX、异步信号、动态 locale 或完整数学库已经闭合。
