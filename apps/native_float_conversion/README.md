# 原生浮点文本转换

为完整 V8 链接中 libc++ locale 的真实缺失符号，接入锁定 LLVM libc 的
`strtof`、`strtod` 和 `strtold`，保留既有 numeric 库的 IA32、C++20、
命名空间、errno 模式和编译参数。5170 条旧对象命令及最终输入顺序保持。

原生反例发现锁定源码的十六进制向下舍入会错误增加最低有效位。
客体测得硬件控制字和库模式读取均正确；修正仅删除 magnitude Down
的增位分支，最近偶数舍入和向上舍入不变。同一头文件的既有 `sscanf`
消费者按它原有参数重新编译，并运行原有 41 个回归检查。

真实消费者检查 43 组独立精确有理数预期位模式、8 种字节对齐、空 endptr、
解析终点、errno、溢出、非正规数、无穷和 NaN；80 位 long double 只比较
有效 10 字节。另检查长尾数字、页尾终止、正负数的四种舍入模式，以及
实际定时器中断和 syscall 返回后的浮点状态。缺少三个提供者的链接必须失败。

八种模式包括正常返回、输入读越界、只读或未映射 endptr 写故障、
运行中取消、保留输入堆的故障、malloc 耗尽后释放恢复和浮点上下文。
验收要求两组内存/CPU 配置、16 次精确 Reap、帧/堆/FP 所有者回收和同伴存活。
结果及完整链接的下一真实阻塞见 [验收记录](acceptance.json)。

公开源码的字节对应检查不等于公开 GN、客体、远程 CI 或 stock 冷读回重跑。
观察到的单函数及 trap 入口栈用量不证明完整调用链上界；多 CPU 配置
不证明并行用户线程。本模块不新增文件服务，生产镜像未变。
完整 V8 ELF、Isolate/JS、浏览器网页、视频和 HTML5 仍待验收。
