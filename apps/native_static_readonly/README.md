# 原生静态数据只读保护

V8 的真实 `FlagList::FreezeFlags()` 需要把加载后的 `v8_flags` 数据页改为只读。
原有动态 VM 接口不能修改静态 ELF 数据，本模块新增独立版本的只读保护 ABI，
并实现 `OS::SetDataReadOnly`。完整目标第48次链接已消除该缺失，当前首错为
`exp2`；链接诊断未穷尽，完整 ELF、Isolate、浏览器、视频和 HTML5 尚未验收。

## 权限契约

- `GTOS_SYS_DATA_READONLY=0x4715`，12字节请求，版本1；仅接受正长度整页范围。
- 范围必须属于当前进程已加载的非执行数据页。代码、初始栈、线程栈、保护页、
  动态 VM、未映射页和借用内核映射均不接受，不提供 PID、物理地址或 CR3 参数。
- 完整复制请求并验证所有页后，才清除 PTE 写权限、更新所有权记录和刷新 TLB。
  不分配页，不修改内容，不解除映射；重复请求成功，没有恢复可写的路径。
- `OS` 包装支持实际原生线程配置，地址和长度均须页对齐；零长度在配置及对齐
  检查后返回。非零失败保留致命拒绝行为，不能以成功空操作代替权限修改。
- 当前调度只在 BSP 运行。非 PAE IA32 没有硬件 NX 保证，本模块提供写保护。

消费者使用对应 GN 宏并运行真实初始化数组；没有替代 `FlagList` 的测试实现。
五个受内核头布局影响的对象重新编译，平台对象使用现有实际 GN 参数，图不变。

32MiB/单CPU和64MiB/四CPU，两种默认及原生线程配置，共20上下文、532项消费者
检查通过。覆盖真实冻结与重复调用、读取和内容保持、主线程与共享线程写入故障
（PF14、错误码7、精确地址）、取消退出、请求位于待保护页内、失败范围保持可写、
非法版本/线长/指针/对齐/溢出/权限。所有上下文、帧、栈和 FP 所有者精确回收，
内核继续运行。四CPU配置不代表原生任务并行调度。
